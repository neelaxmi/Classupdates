          How to get a Gemini API key

          The API key empowers Neelaxmi to parse your answer keys accurately using Google's high-speed Gemini 2.5 Flash model. It is completely free to generate.

          1. Open Google AI StudioVisit aistudio.google.com/apikey and sign in with any standard Google account.
          2. Create your keyClick Create API key. Select an existing Google Cloud project or let AI Studio generate one automatically.
          3. Copy the key tokenKeys start with the prefix AIza. Treat this credential securely like a password.
          4. Paste and saveInput your key into the Gemini API key configuration box at the top of this page and click Save.
          💡 Note: Google's free tier includes generous rate limits. Very large document batches might experience brief pauses while waiting for quotas to refresh. Never share your secret key publicly.

          What the tool does

          Question PDFs are processed directly in your browser. Answer key files are securely routed to Google's Gemini API via your own saved personal API key.

          Your Gemini API key

          Your API key is saved to your account so you do not need to re-enter it. You maintain sole responsibility for token usage quotas and billing limits associated with your key.

          Browser storage

          Cropped question image slices are stored locally in your browser storage and automatically pruned after 7 months (or immediately when browser site data is cleared).

          Account security

          Authentication runs through Firebase. Quiz configurations, custom titles, and final submissions are saved against your personal user account.

          Upload copyright

          You agree to upload only study materials and documents you have authorization to use. You retain full ownership of your uploaded files.

          AI Accuracy

          Automated OCR and AI models can occasionally misread text. Please double-check any answers flagged by the discrepancy checker. Neelaxmi assumes no liability for examination scores.
